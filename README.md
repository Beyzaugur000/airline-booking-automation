# airline-booking-automation
A desktop-based flight reservation system developed using C# Windows Forms for passenger and booking management.
## Features
- Flight reservation management
- Passenger registration system
- Booking and ticket tracking
- Data management with Excel integration
- Interactive Windows Forms user interface

## Technologies
- C#
- Windows Forms
- .NET Framework
- Excel Data Integration

## Project Purpose
This project was developed to manage airline reservation operations through a user-friendly desktop application interface.
